# Projeto de Portfólio — Análise de Churn

## Insight Consulting

Projeto simulado de análise de dados para uma empresa de consultoria B2B.

### Objetivo

Investigar quais características e comportamentos dos clientes estão relacionados ao cancelamento dos serviços (churn).

### Dados

O projeto utiliza dois arquivos:

* `customers_raw.csv`: informações dos clientes.
* `customer_monthly_raw.csv`: histórico mensal dos clientes.

Os dados são simulados e foram criados para fins de estudo e portfólio.

### Problemas de qualidade

Os dados possuem alguns problemas comuns encontrados em bases reais:

* valores nulos;
* registros duplicados;
* espaços extras;
* diferenças de maiúsculas e minúsculas;
* categorias escritas de formas diferentes;
* datas em formatos diferentes.

### Ferramentas

Python, Pandas, PostgreSQL, SQL, Power BI e Git/GitHub.

### Etapas

1. Entender o problema de negócio
2. Conhecer os dados
3. Identificar problemas de qualidade
4. Tratar os dados
5. Fazer análise exploratória
6. Responder às perguntas de negócio
7. Criar o dashboard
8. Apresentar os insights
